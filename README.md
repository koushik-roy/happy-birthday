# Happy Birthday

A small, interactive birthday surprise made with love. Start with a birthday greeting, put the heart back together in a drag-and-drop puzzle, then enjoy a series of animated birthday wishes.

## What’s inside

- A personalized birthday introduction.
- A drag-and-drop heart puzzle with sound effects.
- A celebratory screen that leads into the birthday wishes.
- Animated messages, festive decorations, and birthday music.
- A responsive layout for different screen sizes.

## Run locally

You’ll need [Node.js](https://nodejs.org/) and npm.

```bash
npm install
npm run dev
```

Vite prints a local URL in the terminal; open it in your browser to view the site.

## Build

```bash
npm run build
```

The production files are generated in the `dist` directory.

## Built with

- React and TypeScript
- Vite
- Tailwind CSS and custom CSS
- Lucide icons
